# Fashion ANN Pipeline

End-to-end Fashion-MNIST ANN classification pipeline using TensorFlow, Git, DVC, and Google Drive.

## Project

This project builds a fully-connected Artificial Neural Network (ANN) for Fashion-MNIST classification.

The pipeline includes:

- Data preparation
- Data preprocessing
- ANN training
- Model evaluation
- Git version control
- DVC data/model versioning
- Google Drive DVC remote
